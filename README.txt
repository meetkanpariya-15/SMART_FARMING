SMART FARMING WEBSITE - FINAL SUBMISSION

Files:
- index.html       Main website and navigation
- login.html       Demo login page
- signup.html      Demo registration page
- dashboard.html   Personal profile and saved farm location
- weather.html     Live weather and basic crop suitability estimate
- seeds.html       Seed planting suggestions for 15 crops
- fertilizer.html  Fertilizer and planting guidance
- schemes.html     Government schemes and official links
- prices.html      Estimated crop value calculator
- planner.html     Basic farm plan generator
- style.css        Shared theme and responsive styling
- script.js        Crop information and farming tool functions
- account.js       Browser-only demo account/profile functions

HOW TO RUN
1. Extract the ZIP file.
2. Open the Smart_Farming_Individual_Pages folder.
3. Open index.html in a browser. Bootstrap styling requires internet access.
4. Live weather also requires internet access and uses the Open-Meteo public API.
5. Register an account, then log in. Demo account details are stored in this browser using localStorage.

IMPORTANT PROJECT NOTES
- This is a front-end educational project. Login and registration are demonstrations only; they are not secure production authentication and do not use a server/database.
- Weather data is live when the API is reachable. Crop price values are sample estimates, not live market prices.
- Crop suitability and crop-care information is general educational guidance. Confirm local varieties, fertilizer rates and timing with a soil test and local agricultural experts.
